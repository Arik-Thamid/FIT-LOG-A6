# FitLog

FitLog is a dark, responsive workout library that helps users explore workouts, view workout details, add exercises to today's plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- React Toastify

## Key Features

- Browse workouts from the FitLog API.
- View detailed information for each workout.
- Add workouts to Today's Plan.
- Save workouts for later.
- Sort workouts by Duration, Calories, or Rating.
